- Relationships: A Ninh = chosen family; Chiêu Nguyệt = supervisor/trainer/ally; Phùng Tĩnh = senior/friend; Tống Mù = false mentor/architectural enemy.
- Development: frightened survivor → active hunter → institutional ally → defeats six-century scheme → infiltrates U Tuyền.
- Prohibited inventions: new bloodline, system, past-life trauma, destined lineage, romance declaration, realm shortcut.
- Genre Fit: PASS.
