# Story Memory

Thư mục này là bộ nhớ dài hạn của truyện. Không coi lịch sử chat là nguồn canon.

## File chuẩn

- `canon.md`: sự thật bất biến hoặc đã khóa.
- `current_state.md`: trạng thái mới nhất sau chương đã duyệt.
- `characters.md`: hồ sơ và state của nhân vật.
- `world.md`: thế giới, thế lực, cảnh giới, địa điểm.
- `outline.md`: macro outline + arc hiện hành + chapter beats.
- `chapter_summaries.md`: log sự kiện theo chương.
- `open_loops.md`: setup, bí mật, nhiệm vụ, thù oán và payoff chưa đóng.
- `style_guide.md`: giọng kể, cấm kỵ văn phong và quy tắc audio.

## Quy tắc cập nhật

1. Chỉ cập nhật sau khi chương đã qua review.
2. Canon không được sửa ngầm.
3. Mọi power-up, vật phẩm, thương tích, thay đổi quan hệ phải vào `current_state.md`.
4. Mọi setup có khả năng ảnh hưởng tương lai phải vào `open_loops.md`.
5. Summary chương chỉ giữ fact có hậu quả, không kể lại toàn bộ chương.
