## Loop discipline
- A setup not yet written cannot be treated as an in-world fact learned by characters.
- Closing a loop must update `current_state.md`, `timeline.md`, relevant character knowledge and this file.
- Never reopen a CLOSED source payoff solely to create a new twist.
- Do not add a major open loop without source support or explicit user instruction.
- Minor surface clues may only serve a protected existing loop; they cannot become an independent mystery layer.
